- 대피가방: 가족이 실제로 운반 가능한 주 배낭, 손이 자유로움, 내용물 분류.

- 수중 이동·홍수 횡단은 제품 사용 목적에서 제외.

## 사용·안전 절차
- https://support.seatosummit.com/hc/en-us/articles/19361653630996-How-should-I-correctly-close-a-dry-bag-roll-top-closure : 손상 확인→공기 배출→입구 접기 총 3회 이상→버클 닫기. 전자기기엔 이중 포장 또는 O링 하드 케이스 고려.
- https://niteize.com/runoff-waterproof-hip-pack : 지퍼 최종 끝단까지 닫기, 정기 윤활, 사용 전 손상·기포 확인.
- https://www.ready.gov/kit : 기존 가방을 활용한 휴대용 비상물자와 문서 보호 계획의 일반 참고 자료. 한국 정부의 재난 현장 대피 지시가 우선.
- 물속 이동·침수 지역 접근을 돕는 장비로 설명하지 않음.

## 공개·수익화 금지선
- 공식 제조사 자료와 독립 사용 시험의 **문헌 검증**. 직접 사용 후기, 현물 누수 시험, 장기 내구 시험으로 표현 금지.
- 국내 색상별 모델 SKU·구성·재고·수입 경로, 국내 인증 해당 여부와 실물 패키지의 일치는 미확인.
- 실제 쿠팡파트너스 단일상품 URL을 사용자가 제공하거나 별도 검증하기 전에는 `affiliate:false`, `partnerProductMatched:false`.
- 외부 평가 사이트에 제휴 링크가 존재할 수 있으며 본 사이트의 제품 추천 선정 근거는 판매 수수료가 아니라 사용자 용도·공식 문서·독립 평가·한계 정보다.
