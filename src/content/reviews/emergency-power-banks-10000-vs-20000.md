## 이 보조배터리를 고려할 상황

정전 전에 휴대전화 충전 수단을 하나 더 준비하려는 가정이라면 **삼성 EB-P3401XUKGKR 베이지 10,000mAh**를 살펴볼 수 있습니다. 이 페이지의 쿠팡 제휴 링크는 해당 판매 옵션에 연결돼 있습니다. 기존 보조배터리가 정상이고 필요한 기기를 충전할 수 있다면 새로 구매할 이유는 줄어듭니다.

## 구매 판단에 중요한 실제 사양

| 항목 | 확인할 내용 |
| --- | --- |
| 연결 모델 | EB-P3401XUKGKR, 베이지 |
| 표시 용량 | 환산용량 10,000mAh(3.7V), 에너지 37Wh |
| 충전 단자 | USB-C 2개 |
| 충전 출력 | 삼성 공식 안내상 **기기 1대 연결 시 최대 25W** |
| 동시 충전 | **2대 연결 시 각각 최대 9W**로 안내 |
| 기본 구성 | 제조사 사양에는 배터리팩·충전 케이블·간단 사용설명서 표기 |

숫자가 높아 보여도 **10,000mAh를 휴대전화에 전부 전달할 수 있는 것은 아닙니다.** 실제 충전량과 속도는 변환 손실, 휴대전화 배터리 상태, PD/PPS 지원 여부, 케이블 등에 따라 달라집니다. 25W 표기는 모든 기기를 동시에 25W로 충전한다는 뜻도 아닙니다.

## 이런 경우에는 구매를 보류하세요

- **이미 쓸 수 있는 충전기가 충분할 때:** 먼저 휴대전화와 실제 케이블을 연결해 정상 충전되는지 확인하세요.
- **USB-A만 쓰는 케이블·장비만 있을 때:** 이 상품의 USB-C 포트와 호환되는 케이블이 필요합니다. 별도 연결 상품인 삼성 C to C 1m 케이블은 기존 케이블이 없을 때만 살펴보세요.
- **여러 기기를 최고 속도로 동시에 충전해야 할 때:** 제조사가 명시한 동시 충전 제한을 고려해야 합니다.
- **배터리가 부풀거나 파손돼 있을 때:** 구매 여부와 별개로 손상된 배터리는 사용하지 마세요.
