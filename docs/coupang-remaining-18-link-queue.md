# GuideHollow Ready — 쿠팡파트너스 잔여 18개 상품 등록 원장

기준: 2026-10-29 · 기존 저장소 `emfls/guidehollow-ready` · 구매 허브 `/buying/`

## 현재 사실과 연결 원칙

- 구매 후보 총 **30개**. 기존 검증된 개별 쿠팡파트너스 제휴 URL **12개**, 미발급 **18개**.
- 현재 연결된 브라우저의 쿠팡파트너스 탭 6개는 **이미 발급·등록된** AA 건전지, 헤드랜턴, 구급함, 물티슈, 담요, 캔따개다. 이 6개를 신규 18개에 다시 세지 않는다.
- 브라우저 연결은 현재 **읽기 전용**이다. 새로운 18개의 파트너스 개인 전환 URL을 생성하거나 로그인 UI를 직접 조작할 수 없으며, 일반 쿠팡 링크를 제휴 링크라고 표기하지 않는다.
- 다음 표의 상품 검색어는 **발급 대상 품목을 찾는 내부 검색어**다. 브랜드/옵션은 쿠팡파트너스에서 상품 상세·전원·식품 보관·가족 적합성을 확인해 결정한다.
- 실제 발급된 정적 HTML(상품 링크 `https://link.coupang.com/a/...` + 정확히 같은 상품의 이미지 URL/alt)을 전달받으면 중앙 `src/data/affiliate-product-visuals.ts`와 `src/data/buying-guide.ts`에 한 번만 추가하고, `/buying/`의 구매하기 버튼 및 관련 프로토콜 카드에 동일한 데이터를 적용한다. 원래 HTML의 `referrerpolicy="unsafe-url"`은 재사용하지 않고 기존 안전한 링크 속성을 유지한다.

## 매칭 및 검수 완료 조건

1. `<a href>`의 Coupang 단축 URL과 `<img alt>`의 정확한 **상품명·옵션·수량**을 같은 상품으로 확인한다.
2. 키와 내부 ID를 일대일로 연결한다. 각 후보는 한 개의 정확한 파트너 링크가 발급되기 전까지 `data-buy-linked="no"`를 유지한다.
3. 쿠팡 상품 가격·할인·재고·배송일은 정적 페이지에 고정하지 않는다.
4. 이미지가 제휴 배너일 경우 기존 `ProductPhoto` 이미지 영역에 한정하고 상품명/가짜 버튼이 겹치지 않도록 모바일을 확인한다.
5. `rel="sponsored nofollow noopener noreferrer"`, 새 창 표시, **구매하기** 버튼, 쿠팡파트너스 수수료 고지를 유지한다.
6. 구매 가이드의 누적 대비 기간, 상세 체크리스트 읽기 전용 동작, 긴급 행동 우선 규칙을 보존한다.
7. 최종적으로 `linked=30`, `pending=0` 상태가 되면 320/375/390/430/768/1024/1440px 자동 검사를 통과해야 한다.

## 사용자 입력 형식

사용자에게 필요한 유일한 외부 작업: 쿠팡파트너스 **정확한 18개 개별 상품**을 검색·검토한 후 각 상품의 `링크 생성 → HTML 태그 복사` 결과를 한 메시지(또는 여러 메시지)로 제공한다. 각 태그의 `alt`로 상품을 식별할 수 있지만, 식별이 어려운 영유아/반려동물 품목은 **내부 ID도 함께 표기**한다.

등록된 12개 제휴 링크는 변경·삭제하지 않는다.
