## 검증 근거 및 범위

이번 구매 후보 우선순위의 **검증 근거**는 삼성전자 국내 모델별 공식 사양, 국가 제품안전정보센터 KTC 안전확인 원장, Fenix Korea 제품 목록, Sea to Summit 국내 판매 목록, 솔벤텀 코리아 1624W 규격과 앞선 제품별 독립 평가 자료입니다. 국내 판매 사이트에서 모델명이 보인 사실은 특정 쿠팡 옵션·정품·재고·사용기한·제품 상태 검증을 뜻하지 않으므로, 제휴 승인은 전부 보류했습니다.

## 제품 검증 13종과 실제 구매 추천 승인은 서로 다릅니다

재난용품을 고를 때 **제조사가 설명한 사양을 확인했다는 사실**과 **지금 국내에서 판매하는 특정 상품 옵션이 그 모델이라는 사실**은 다릅니다. 국내 안전확인 모델이 존재한다는 자료도 포장에 들어 있는 제품이 같은 생산품인지, 배터리 수명이 괜찮은지, 판매자가 정확한 옵션을 발송하는지까지 증명하지 않습니다.

이 사이트는 이미 손전등·헤드랜턴, 비상 라디오, 보조배터리, 드라이백·파우치, 구급 드레싱, 비상담요·위생티슈 등 **개별 제품 13종의 공개 사양과 외부 평가를 편집 검증**했습니다. 이번에는 그 자료를 이용해 **한국에서 실제로 구매할 상품을 더 조사할 순서**를 정했습니다. 아래 순서는 상품의 성능 순위·판매 순위·가격 순위가 아닙니다.

현재 **검증된 쿠팡파트너스 상품 URL은 하나도 없습니다.** 다른 쇼핑몰 페이지를 출처로 인용하더라도 해당 사이트에서 구매하라고 권하는 광고가 아닙니다.

## 실제 쿠팡파트너스 상품을 승인하는 6단계

1. **상품 신원 일치:** 공식 모델명뿐 아니라 전체 모델번호, 세대, 색상, 용량·크기, 지역판, 기본 구성품 확인.
2. **필요한 인증·표시:** 해당 품목의 KC 등 법적 대상 여부와 필요 인증의 원장·실제 판매품 표시 확인. 외국 CE·IP 수치를 국내 KC로 오인하지 않음.
3. **안전·성능 근거:** 제조사 설명서, 독립 평가, 금지 사용법과 결함·한계 자료 확인. 독립 시험이 다른 크기나 세대이면 차이를 표시.
4. **상태·사용기한:** 충전지의 손상·생산 세대, 멸균·위생용품의 로트·사용기한·밀봉 상태, 손전등의 호환 전지 확인.
5. **판매 옵션과 링크:** 사용자가 제공한 실제 **쿠팡파트너스 단일상품 HTTPS URL 또는 정적 `<a>` 태그**를 열어 위 정보와 연결되는 상품·옵션을 확인. 판매 페이지 정보가 모호하면 보류.
6. **광고 고지 및 최종 점검:** 링크가 확인된 경우에만 해당 글의 제휴 고지를 켜고 구매 버튼을 연결. 가격·재고·할인·구매후기를 만들어 넣지 않음.

### '검증 완료'라는 말의 범위

- **사양 검증:** 제조사 모델과 공개 성능·독립 평가 근거가 일치. 공개 비교 원고에 들어갈 수 있음.
- **국내 판매 후보:** 모델 코드나 판매규격을 확인했지만, 실제 옵션·인증·소모품 상태·제휴 URL은 미완료.
- **제휴 승인:** 위 6단계에 필요한 사실과 실제 링크가 확인된 **특정 판매 옵션에만** 적용. 한 상품을 승인해도 다른 판매자가 파는 유사 상품에는 자동 적용하지 않음.

**2026년 10월 28일 현재: 개별 제품 13종 문헌 검증, 쿠팡파트너스 옵션 승인 0종, 제휴 링크 0개.** 완성형 72시간 키트 70280·70380은 13개 개별 제품 카드에 포함하지 않으며, 별도 구성표 감사의 **구매 추천 보류** 사례입니다.

이 순위는 편집 검증의 **다음 확인 순서**이며 구매·성능 추천 순위가 아닙니다. 실제 구매 전 판매 옵션과 표시 사항을 다시 확인하고, 당국의 재난 행동요령을 우선하세요.
