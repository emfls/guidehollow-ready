## 이 검증표의 목적

'공식 인증', '정품', 'KC', '방수', '세균 차단', '10년 비축' 같은 광고 단어는 서로 다른 사실을 표현합니다. 특히 재난용품을 한 번 구매해 오래 보관하려면 **① 정확한 모델과 세대 ② 적용되는 안전 표시 ③ 실제 판매 옵션 ④ 사용할 때의 소모품 상태**를 개별적으로 확인해야 합니다.

**검증 근거**는 한국 제품안전정보센터에 공개된 인증 원장, 삼성전자·솔벤텀·페츨의 공식 제품 문서, 국내 유통 상품의 공개 모델번호입니다. 이 글은 제품을 직접 구매·시험하거나 판매자의 창고 재고를 확인한 결과가 아닙니다.

[제품안전정보센터 EB-P3400 원장](https://www.safetykorea.kr/search/searchPop?certNum=XU102985-22001C)은 모델명 EB-P3400, KTC, 안전확인·적합, 2022년 12월 9일 인증을 표시합니다. [EB-P4520의 A 접미 번호 원장](https://www.safetykorea.kr/release/certDetail?certNum=XU103282-23002A&certUid=5664089)은 모델명 EB-P4520, KTC, 안전확인·적합, 2023년 11월 7일 인증을 표시합니다.

반면 [삼성전자서비스 EB-P4520 국내 유통 정보](https://www.samsungsvc.co.kr/shop/product/0000116005)는 **KC XU103282-23002**로 적혀 있습니다. **-23002와 -23002A의 관계를 확인 없이 동일한 인증 건으로 합치지 않았습니다.** 본체 라벨·포장 정보가 제조사 판매 페이지 및 원장과 일치하는지 확인해야 합니다. 지금 확인한 인증은 **개별 구매품이 정품이라는 판정도, 충전 반복 수명이나 출력 성능에 대한 국가 보증도 아닙니다.**

삼성의 2026년형 10,000mAh 배터리팩은 별도 모델 **EB-P3401XUKGKR**입니다. 기존 EB-P3400의 독립 방전 테스트나 KC 번호를 3401의 자료인 것처럼 재사용하지 마세요.

### 실제 판매 페이지에서 확인되는 단서

국내 온라인 판매처 중 일부가 EB-P4520XUEGKR이라는 **전체 상품 코드**와 KC XU103282-23002를 공개합니다. 그러나 상품명에 단순히 '삼성 20,000mAh 45W'라고 적힌 경우에는 다른 지역판·세대가 섞일 수 있습니다. 판매자가 올린 이미지만으로 생산 로트나 배터리 상태를 확인할 수 없으며, 최종 결제 전에 현재 상품 옵션을 다시 확인해야 합니다.

## 2026년 10월 28일 추가 확인: 쿠팡 EB-P4520 상품번호와 KC 표기

웹 검색에 공개된 쿠팡의 **삼성 20,000mAh·45W·USB-C 3포트 제품**에서 **상품번호 `8011542256`, 옵션번호 `22352360578`**을 확인했습니다. 해당 검색 색인의 상품 필수정보에는 모델 **`EB-P4520`**, KC 인증번호 **`XU103282-23002A`**가 명시되어 있습니다. 이는 [제품안전정보센터가 공개한 EB-P4520의 A 접미 인증번호](https://www.safetykorea.kr/release/certDetail?certNum=XU103282-23002A&certUid=5664089)와 문자 단위로 일치합니다.

그러나 **쿠팡의 표시 모델은 한국 전체 SKU `EB-P4520XUEGKR`가 아니라 `EB-P4520`**입니다. 삼성 [한국 공식 제품 정보](https://www.samsung.com/sec/support/model/EB-P4520XUEGKR/)는 전체 SKU·베이지색·0.3m 케이블을 확인해 주지만 **KC 번호가 `XU103282-23002`(A 없음)**으로 표기됩니다. 별도 국내 판매처가 전체 한국 SKU와 **`-23002A`**를 같이 기재하는 사례도 있으나, **제조사가 표시한 번호와 원장 A 접미 번호의 관계** 또는 **쿠팡에서 현재 선택되는 정확한 판매 옵션의 본체 라벨**을 증명하지는 않습니다.

**조회 한계:** 검색 색인은 이전에 수집된 쿠팡 상품정보일 수 있고, 이번 재점검에서는 쿠팡 상세페이지의 직접 열람이 접근 차단(403·자동화 차단)되어 **현재 판매자·옵션·실제 판매 가능 여부·정확한 포장 구성**을 실시간 확인할 수 없었습니다. 유사 제목의 다른 쿠팡 URL도 별도 상품번호·판매자 옵션 식별자를 사용합니다. **따라서 이 자료는 상품 후보를 특정한 것이지 판매 옵션·쿠팡파트너스 링크를 승인한 것이 아닙니다.** 일반 쿠팡 URL을 임의로 파트너스 링크로 변환하지 않습니다.

**판정: EB-P4520 모델의 A 접미 KC 적합 원장과 쿠팡 색인 표기 일치 / 정확한 한국 판매 옵션·본체 라벨·파트너스 URL 미검증 → 제휴 링크 보류.**

## 2. 손전등·헤드랜턴은 CE·IP·KC를 구분

Petzl의 공식 모델 표기에서 **TIKKINA 300 블랙은 E060AB00**, **ACTIK CORE 625 블랙은 E065AB00**입니다. 두 제품의 설명에는 **CE**, **IPX4**가 표시됩니다. **CE는 유럽의 규정 적합성 표시이고 IPX4는 방수 시험 등급**으로, 이 정보만으로 한국 전파법·전기용품 KC 대상 여부 또는 국내 판매품 적합성이 자동 확인되는 것은 아닙니다.

ACTIK CORE에는 전용 CORE 충전식 배터리가 기본 구성이고 AAA 3개로도 동작하지만, TIKKINA는 AAA 3개가 기본이고 CORE 충전지는 별도입니다. 판매자가 **'충전 가능'**이라고만 표시하면 CORE 배터리가 포함됐다고 추정하지 말고 반드시 기본 구성품을 확인하세요. ACTIK CORE의 전용 배터리는 제조사 보증 표기가 램프 본체와 다르므로, 장기간 비축 시 충전 상태와 충전 규격을 별도 점검합니다.

Fenix **E12 V3.0**은 국내 공식 수입업체의 온라인 제품 목록에서 동일 모델명을 확인했습니다. 하지만 **'공식 수입' 문구만으로 개별 제품의 KC 필요 여부·인증 완료를 판정하지 않았습니다.** 이 손전등에 사용하는 AA 건전지의 종류와 금지 전지(14500 3.7V 등)를 제조사 설명서와 맞춰야 합니다.

## 3. 라디오는 국내 AM/FM 대역과 해외 기상 경보를 구별

Sony **ICF-P26**은 AA 2개를 사용하는 아날로그 AM/FM 모델입니다. 국내 가격비교에서 같은 기기 모델이 검색된다는 사실은 **한국 내 정식 유통·지역별 방송 수신·KC 적합성**을 증명하지 않습니다.

Sangean **MMR-99**는 지역판에 따라 미국 NOAA WX 기능 또는 DAB+ 수신 기능이 혼재합니다. 한국에서 검색되는 일부 MMR-99 상품은 **해외직구·미국 기상 채널 지원형**으로 확인되어, 앞서 검증한 국제 AM/FM판과 동일하다고 승인하지 않았습니다. NOAA WX를 한국의 재난문자·민방공 경보 수신 기능이라고 설명하는 판매 문구를 그대로 믿지 마세요.

## 4. 구급·위생 소모품은 사용기한을 숫자로 만들어내지 않습니다

3M/솔벤텀의 **Tegaderm 1624W**는 공식 한국 제품 문서에서 **6×7cm 투명 필름, 100매/상자**로 확인됩니다. 이는 **흡수 패드가 없는 필름형 드레싱**이므로 압박용 거즈·응급 지혈용품을 대신할 수 없습니다. 제조사 웹페이지의 의약외품 표시는 확인했지만, **개별 판매 로트의 멸균 포장·유통기한·보관 조건·구성 수량**은 포장이나 공급처 기록으로 확인해야 합니다. 공개 규격만으로 제품에 일률적인 유효기간을 부여하지 않았습니다.

Sea to Summit **Wilderness Wipes Compact 12매** 역시 과거 제품 코드 AWWC가 언급되지만, **현재 한국 판매 포장의 생산 코드·사용기한·성분 표시**가 동일한지 확인되지 않았습니다. 재난가방에 오래 넣어 둔 밀봉 물티슈는 포장 파손·씰 상태·표시 기한을 확인하고, 세정용 티슈를 손 소독제나 영유아 전용 물티슈로 바꿔 쓰지 마세요.

**SOL 비상담요 0140-1222**는 국내 유통업체의 동일 모델 코드 판매 정보까지 확인했습니다. 다만 정확한 판매품 배치·포장 상태·변질·찢김은 제품을 직접 확인해야 합니다. 비상담요의 **복사열 반사율**은 실내외 체온 유지를 보증하는 인증 숫자가 아닙니다.

## 5. 비상가방·방수 파우치의 모델·규격 확인

Sea to Summit **Big River Dry Bag 35L**는 국내 판매처에서도 35L와 색상 옵션으로 검색됩니다. 판매자의 별도 내부 코드(예: B137STS-ABRDB35)를 **제조사 전 세계 공통 SKU로 오해하지 않습니다.** 제품 크기·원단·세대가 제조사 페이지와 일치하는지, 롤탑 구조가 침수를 보증하지 않는지 확인하세요.

**Lightweight Dry Bag 5L**, **Nite Ize RunOff Hip Pack ROHP-09-R8**도 제조사 모델과 사용 목적은 검증했지만 국내 판매 단위, 실제 포장 SKU와 방수 지퍼 상태는 확인 전입니다. 제조사 IP67이나 원단 내수압은 **국내 KC 안전확인 여부와 별개의 기능 시험 주장**입니다.

## 6. 쿠팡파트너스 링크를 연결하기 전의 4단계 승인

1. **정확한 상품:** 제조사 모델, 용량·크기·색상·지역판·세대·구성품이 판매 페이지 옵션과 일치하는가?
2. **법정 표시:** 해당 품목에 적용되는 법적 표시와 실제 인증번호를 공식 원장·제품 라벨에서 확인했는가? KC가 일률적으로 필요한 물품인지도 품목별로 구분한다.
3. **상태·유효기간:** 약품·멸균 드레싱·위생 티슈는 사용기한/포장 상태, 건전지·충전지는 노화/손상/보관 조건을 확인했는가?
4. **제휴 링크:** 사용자가 제공한 쿠팡파트너스 정적 상품 URL 또는 단일 `<a>` 태그가 그 **동일 상품 옵션**으로 연결되는가? 미확인이면 상품 카드에 링크를 붙이지 않는다.
