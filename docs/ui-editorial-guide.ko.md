# GuideHollow Ready — 모든 채팅 공통 디자인·원고 기준

최종 검토: 2026-10-28 · 적용 사이트: https://ready.guidehollow.com · 운영 브랜치: main

## 1. 사용자가 처음 보는 화면 — 기존 다크 테마 유지

- **인스타그램처럼 설명 없이도 쓸 수 있는 탐색 구조**를 지향하되 앱을 복제하거나 감성·색상을 그대로 모방하지 않는다.
- 첫 화면에서는 가장 필요한 행동 하나를 강조한다. 모바일 하단의 **홈 / 행동 / 체크 / 준비물 / 제품** 5개 메뉴를 유지한다.
- 한 카드에는 **하나의 목적과 하나의 기본 행동**만 둔다. 카드 안에 관련 없는 링크·기술 로그·추적코드·긴 주의 문구를 섞지 않는다.
- 그리드 안 같은 행의 카드는 동일한 높이·여백·버튼 위치로 정렬한다. 이미지가 있는 상품은 별도 추천 영역으로 빼 카드 구조를 일정하게 한다.
- 모바일 320–430px를 먼저 고려한다. 모든 폼·테이블·장바구니에 가로 화면 넘침을 만들지 말고, 버튼은 터치 가능한 높이(최소 44px)를 확보한다. 텍스트 강제 줄바꿈을 줄이고 단어 단위로 자연스럽게 흐르게 한다.
- **기존 다크 테마는 변경 금지:** `src/styles/global.css`의 Night Operations 팔레트(`#0e151d`)가 기준이다. `src/styles/night-layout.css`는 다크 기반 카드/모바일 레이아웃 보완 전용이며 밝은 테마로 전환하면 안 된다.
- 스타일은 `src/styles/night-layout.css`가 공통 기준이다. 새 채팅이 `src/styles/global.css`에 또 다른 상충 스타일을 붙이지 않는다. 꼭 필요한 지역 CSS만 사용하고, 전역 변경은 모바일·PC 공통 회귀검사를 거친다.
- 중요한 링크와 안전 행동을 CSS `line-clamp`로 숨기지 않는다. 짧은 **보조 설명**만 2~3줄로 제한하고 나머지 설명은 본문·상세 화면·펼쳐보기에서 제공한다.

## 2. 쉬운 한국어 원고

- 제목은 '무엇이 필요하고 언제 쓰는지'를 드러내는 짧은 말로 작성한다. **기술 검증 절차, 상품 ID, 쿠팡 제휴 URL, 내부 승인 단계**를 제목이나 본문 첫 부분에 노출하지 않는다.
- 첫 1~2문단은 **일상 상황 + 도움이 되는 이유**. 이후 장점 2~3개 → 구매 전 주의할 점 1~2개 → 어디서 준비/확인할지 순서로 쓴다.
- 1문단은 모바일 2~3문장 이내로 나누고, 하나의 소제목에 하나의 질문만 답한다.
- **긴 표, 실측 자료, 사양별 세부 차이, 확인 URL 전체 목록**은 필요할 때만 펼쳐보는 근거 영역으로 이동한다. 원본을 삭제하지 않고 공개 검증 근거 또는 `docs/products`에서 찾을 수 있게 한다.
- 전문용어가 꼭 필요하다면 같은 문장에서 쉬운 뜻을 붙인다. 의미가 없는 수사·반복된 고지·번역투·이중부정을 줄인다.
- 빈 페이지와 비슷한 상태를 억지로 상품 목록으로 채우지 않는다. 판매·안전성 검증이 아직 끝나지 않은 상품은 **정보만 제공**하고 구매 버튼을 쓰지 않는다.

## 3. 재난 행동요령의 안전 원칙

- 첫 행동, 절대 하면 안 되는 행동, **당국의 실시간 지시가 우선**이라는 내용은 **펼쳐보기에 숨기지 않는다**.
- 긴 예방 설명·근거·세부 예외만 점진적으로 펼쳐볼 수 있다. 직접 링크되는 `id`는 유지하며 접힌 요소 안에 넣을 때는 앵커 동작을 직접 확인한다.
- 내용 짧게 만들려고 위험에 필요한 조건을 누락하지 않는다. 공습·핵·화학·침수·산불처럼 대피 방향이 달라지는 상황을 하나로 뭉개지 않는다.
- 기본 72시간 체크리스트와 국내 공식 장기 비축 권고를 구분한다. 가족 유형, 의료·영유아 준비, 개인별 안전정보는 계속 제공한다.

## 4. 제품 소개와 제휴 버튼

- **쿠팡에서 실제 판매 중인 정확한 모델·옵션**, 제조사 사양, 독립 평가, 해당 품목의 국내 안전정보를 확인한 다음 제휴 단축 URL의 최종 상품·옵션 일치까지 검증한다.
- 승인된 상품: 첫 화면에 정확한 제품 이미지 → 한 줄 장점 → 읽기 쉬운 구매 버튼. 광고 고지는 상단에 자연스럽고 명확하게 표시한다.
- iframe·스크립트를 직접 렌더링하지 않는다. 검증한 개별 상품의 정적 이미지와 제휴 URL을 안전하게 분리 사용한다. `rel="sponsored nofollow noopener noreferrer"`를 유지한다.
- **상품을 사면 모든 대비가 끝난다**는 보장, 재고·할인 허위표시, 소비자 사용 후기 사칭, 구입하지 않은 장비 실물 시험을 했다는 주장은 금지한다.
- 완성형 세트 페이지는 필요한 **6개 분야를 한눈에 보고 부족한 물품만 구매**하도록 한다. 직접 상품 링크가 없는 분야는 투명하게 유지한다.

## 5. PR·새 원고 검수 체크

- 새 PR은 디자인 가이드·전문용어·본문 길이·카드 정렬·모바일 폭·키보드 포커스·광고 고지·외부 URL·실제 구매 옵션을 검토한다.
- 기존 페이지의 폼 ID, 체크/복원 기능, 로컬 저장 키, 접힌 백업의 이벤트 기능을 변경하지 않는다.
- `npm ci && npm run check && npm run build && npm run verify`가 통과해야 하며, 실제 배포도 확인한다.
- **검색 노출 설정 `noindex`**, Naver 메타 인증, 공식 경보 서비스가 아니라는 고지, RSS·사이트맵·CNAME 유지.
- 기능 검증과 모바일 시각 검증을 구별한다. 브라우저에서 기기별 뷰포트를 확인하지 못하면 시각 검증 완료라고 보고하지 않는다.

본 문서는 기존 [콘텐츠·광고 운영 원칙](./editorial-policy.ko.md)을 대체하지 않고, 그 아래에서 **모든 채팅이 공유하는 표현·화면 설계 규칙**으로 적용한다.

## 2026-10-28 실제 위기 사용자 점검 보완 (필수)

- 홈페이지 최상단을 **긴급 행동 / 평상시 준비**로 분리하고 '지금 경보를 받았나요'를 먼저 제공한다. 다른 안내보다 당국 실시간 지시가 우선이다.
- 공습·화생방·핵의 첫 **세 가지 행동을 기본 펼침**으로 표시한다. 자세한 자료만 접을 수 있으며, 위협마다 대피 방향이 다르다는 주의는 접지 않는다.
- 공식 민방위 대피시설로 직접 연결한다. 지도에서 지역과 시설 종류는 사람이 선택해야 하므로 실시간 위치 자동 판정이나 시설 개방을 주장하지 않는다.
- 인터넷 없이 사용하는 요약카드 /offline/ready-card.html은 다운로드하면 순수 HTML 한 파일로 열 수 있고, 인쇄하여 PDF로 보관할 수도 있다. 다운로드 전에 반드시 행동카드와 최신 정부 안내가 다를 수 있음을 고지한다.
- 영유아·고령자 등 가족별 긴급 동선과 별도 작성·인쇄 가족카드 /family-card/를 제공한다. 개인정보는 서버에 보내지 않고 공용 기기 이용 시 주의를 알려준다.
- 한 카드에 하나의 행동, 320·390·430px에서는 세로 배치·44px 이상 터치 대상을 우선한다. 모바일 실제 시각 테스트와 기능 테스트는 구분해 기록한다.
