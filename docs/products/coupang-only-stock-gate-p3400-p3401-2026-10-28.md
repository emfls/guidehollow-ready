- **신규 선정은 C1보다 낮으면 금지**. 현재 쿠팡 직접 접속을 403/Access Denied로 확인하지 못한 상황에서는 쇼핑 검색 결과가 있더라도 C1로 승격하지 않음.
- 판매자/옵션별 재고는 변할 수 있어 C1에는 점검일과 옵션 ID 필요. **다른 판매자의 옵션은 별도로 검증**.
- 기존 13개 제품의 비교 카드는 과거 사양 연구 자료이며 지금 쿠팡에서 판매 중인 구매 추천으로 자동 간주하지 않음. 기존 원고에 판매상태/한계 고지를 추가.
- 본 브랜치의 `partnerProductMatched:false` 및 `affiliate:false` 유지. 이미 main에 다른 채팅이 승인한 제휴 제품은 이번 규칙으로 임의 삭제/수정하지 않음.
- 품절이 확인된 **특정 옵션은 신규 선정 불가**. 동일 모델의 플랫폼 전체가 품절이라는 추론은 금지.
- 새 상품을 임의로 추가하려고 기존 제품 모델의 독립 테스트를 신형 모델로 전용하지 않음.
