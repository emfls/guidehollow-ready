## 2. 직접 열람 시도와 기술적 한계 (사실 그대로 기재)

- 2026-10-28 웹 검색: 쿠팡 상품에 `EB-P4520`, `XU103282-23002A`, 45W/20,000mAh/3 USB-C 포트 및 0.3m 케이블 정보가 **색인된 페이지**로 검색됨.
- 쿠팡 페이지 직접 재열람: HTTP 403 및 robots/bot 차단으로 실패. 별도 JS 렌더링 읽기도 **`bot_blocked`**(두 URL 모두). 색인된 자료는 수개월 전 캐시일 수 있으며 **실시간 조회·현물 사진/라벨 검증**과 구별.
- 제품안전정보센터에서 A 없는 `XU103282-23002` 상세 페이지 직접 확인 시도: 해당 링크 조회 오류/시간초과로 **원본 문서 확인 불가**. 이것은 '번호가 존재하지 않는다'는 증거가 아님.
- 삼성 공식 `XU103282-23002`와 국가 원장의 `XU103282-23002A`는 반드시 각각 정확히 인용. **접미자 변경·확장 승인·동일 인증범위라고 추정하지 말 것.**
- 다른 국내 판매처(SSG)는 같은 전체 SKU와 `A` 접미 KC 번호를 나란히 기재. 이것만으로 공식 원장 속 `A` 없는 번호의 관계가 해명되거나 쿠팡 해당 옵션과 일치함을 입증하지 못함.

## 4. 사용자가 추가 제공할 수 있는 최종 검증 자료

- 실제 사용할 **쿠팡파트너스 단일상품 URL** `https://link.coupang.com/...` 또는 승인된 정적 단일상품 `<a href="...">...</a>`. 쿠팡 일반 상품 URL이나 iframe은 파트너스 URL로 자동변환하지 않음.
- 판매자/옵션 화면의 **정확한 전체 모델코드 EB-P4520XUEGKR**, 베이지, 20,000mAh, 45W, USB-C 0.3m 케이블 포함 표시.
- **본체/상품 박스 KC 번호 라벨**(개인정보·일련번호 등 필요 없는 데이터는 가림)과 `-23002` / `-23002A`의 관계를 설명한 제조사·KTC 확인자료.
- 고객에게 발송되는 상품의 보관/전원/반품 정책과 정상 인증·국내 AS 범위 확인.
- 제품을 구매·개봉하기 전에는 포장/생산 배치를 강제로 확정할 수 없으므로 **제품별 실물확인 미완료 상태를 고지**하고 판매자 설명을 임의 인증하지 않음.
