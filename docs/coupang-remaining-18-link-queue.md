- 구매 후보 총 **30개**. 기존 검증된 개별 쿠팡파트너스 제휴 URL **12개**, 미발급 **18개**.

## 매칭 및 검수 완료 조건

1. `<a href>`의 Coupang 단축 URL과 `<img alt>`의 정확한 **상품명·옵션·수량**을 같은 상품으로 확인한다.
2. 키와 내부 ID를 일대일로 연결한다. 각 후보는 한 개의 정확한 파트너 링크가 발급되기 전까지 `data-buy-linked="no"`를 유지한다.
3. 쿠팡 상품 가격·할인·재고·배송일은 정적 페이지에 고정하지 않는다.
4. 이미지가 제휴 배너일 경우 기존 `ProductPhoto` 이미지 영역에 한정하고 상품명/가짜 버튼이 겹치지 않도록 모바일을 확인한다.
5. `rel="sponsored nofollow noopener noreferrer"`, 새 창 표시, **구매하기** 버튼, 쿠팡파트너스 수수료 고지를 유지한다.
6. 구매 가이드의 누적 대비 기간, 상세 체크리스트 읽기 전용 동작, 긴급 행동 우선 규칙을 보존한다.
7. 최종적으로 `linked=30`, `pending=0` 상태가 되면 320/375/390/430/768/1024/1440px 자동 검사를 통과해야 한다.
